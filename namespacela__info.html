Detailed Description

Decode the info exit code of the LAPACK routines into a la_state.

One elemental handler per LAPACK routine, handle_<routine>, shared by every procedure that calls it. Each handler takes the caller's name first, which becomes the where_at of the returned state, then the exit code, then the routine arguments its messages need.

One classification holds for every routine: an invalid dimension of the user's data is a LINALG_VALUE_ERROR; an invalid argument the library chose (a job character, a triangle selection, a workspace size) is a LINALG_INTERNAL_ERROR; a failure that info > 0 reports is a LINALG_ERROR; any code that LAPACK does not document is a LINALG_INTERNAL_ERROR.
