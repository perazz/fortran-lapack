Detailed Description

Compute the sign and the logarithm of the absolute value of the determinant.

This subroutine computes \( \det(A) = sign \cdot e^{logabsdet} \) for a real or complex square matrix \( A \), from its LU factorization. The logarithm does not overflow or underflow where the determinant itself would.

Parameters
[in,out]aThe input square matrix of size \( [n, n] \). If overwrite_a is true, it is overwritten by its LU factorization.
[out]signThe sign of the determinant, of the same type and kind as \( A \): \( \pm 1 \) for a real matrix, a complex number of unit modulus for a complex one, and 0 for a singular matrix.
[out]logabsdetThe natural logarithm of \( |\det(A)| \), a real of the kind of \( A \); \( -\infty \) for a singular matrix.
[in]overwrite_a(Optional) If .true., A may be overwritten and destroyed. Default is .false..
[out]err(Optional) A state return flag. If an error occurs and err is not provided, the subroutine will stop execution.
Note
The subroutine is pure. A singular matrix is not an error: it returns sign = 0 and logabsdet \( = -\infty \).
