Detailed Description

Compute the determinant of a rectangular matrix.

This function computes the determinant of a real or complex rectangular matrix \( A \). The determinant is calculated using LU factorization.

Without err the function is pure, takes A as intent(in), and stops on error; it is the function behind .det.. With err it returns the error state instead, and can overwrite A.

Parameters
[in,out]AThe input square matrix of size \( [m, n] \). If overwrite_a is true, the contents of A may be modified during computation.
[in]overwrite_a(Optional, with err only) If .true., A may be overwritten and destroyed. Default is .false..
[out]err(Optional) A state return flag. If an error occurs and err is not provided, the function will stop execution.
Returns
The determinant of the matrix \( A \). The result is a real scalar value of the same kind as the input matrix.
Note
This function relies on a matrix factorization approach (e.g., LU decomposition) to compute the determinant efficiently from the getrf backend.
A singular matrix is not an error: its determinant is 0.
Warning
If overwrite_a is enabled, the original contents of A will be lost.
