Detailed Description

Workspace sizes for the matrix exponential.

This subroutine returns the sizes of the working arrays that matrix_exp needs for a matrix of the size of \( A \), so that repeated calls perform no internal allocation.

Parameters
[in]AThe input square matrix of size \( [n, n] \). Only its size is read.
[out]lworkThe minimum size of work, \( 4 n^2 \).
[out]liworkThe minimum size of iwork, \( n \).
