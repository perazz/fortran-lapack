Detailed Description

Compute an integer power of a square matrix.

This function computes \( A^n \) for a real or complex square matrix \( A \) and an integer \( n \), by repeated squaring: about \( 2 \log_2 |n| \) matrix products. \( A^0 \) is the identity matrix, also for a singular \( A \), and a negative power is the power \( (A^{-1})^{|n|} \) of the inverse.

Parameters
[in]AThe input square matrix of size \( [m, m] \).
[in]nThe power, an integer(ilp).
[out]err(Optional) A state return flag. Without it the function is pure, and an error stops execution.
Returns
The matrix \( A^n \), of the same type, kind and size as \( A \). With err, an error returns an empty matrix.
Note
The matrix products use the BLAS gemm; the inverse comes from invert.
