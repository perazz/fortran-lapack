Detailed Description

Compute the exponential of a square matrix in a subroutine.

This subroutine computes \( E = e^{A} \) for a real or complex square matrix \( A \), by scaling and squaring with a Pade approximant. It either overwrites \( A \) with its exponential, or writes the exponential into a second matrix \( E \).

Parameters
[in,out]AThe input square matrix of size \( [n, n] \). Without E, it is overwritten with \( e^{A} \).
[out]E(Optional) The output matrix of size \( [n, n] \).
[in]order(Optional) Order of the Pade approximant. Default is 10.
[in,out]work(Optional) Workspace of the same type and kind as \( A \), of size at least the lwork returned by expm_space.
[in,out]iwork(Optional) Integer workspace of size at least the liwork returned by expm_space.
[out]err(Optional) A state return flag. If an error occurs and err is not provided, the subroutine will stop execution.
Note
The subroutine is pure. With both work and iwork present it allocates no work arrays of its own.
