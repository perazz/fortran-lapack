Detailed Description

Compute the condition number of a matrix.

This function returns the condition number \( \kappa(A) = \|A\| \cdot \|A^{-1}\| \) of a real or complex matrix \( A \), in the norm that order selects:

  • 2-norm (the default), \( \sigma_{max} / \sigma_{min} \) from the singular values: order = 2 or "2". \( A \) may be rectangular.
  • 1-norm, order = 1 or "1", and infinity norm, order = huge(0) or "inf": LAPACK's gecon estimate from the LU factorization of the square matrix \( A \).
  • Frobenius norm, order = "fro": from the explicit inverse of the square matrix \( A \).
Parameters
[in]aThe input matrix \( A \) of size \( [m,n] \).
[in]order(Optional) The norm, as an integer(ilp) or a character string. Default is 2.
[out]err(Optional) A state return flag. Without it the function is pure, and an error stops execution.
Returns
The condition number, a real scalar of the kind of \( A \): \( +\infty \) for a singular matrix, and 0 if the computation failed.
Note
Unlike mnorm, which reads order = 2 as the Frobenius norm, cond reads it as the spectral norm, as NumPy does.
