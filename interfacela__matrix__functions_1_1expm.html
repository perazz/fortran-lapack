Detailed Description

Compute the exponential of a square matrix.

This function computes \( E = e^{A} \) for a real or complex square matrix \( A \), by scaling and squaring with a Pade approximant.

Parameters
[in]AThe input square matrix of size \( [n, n] \).
[in]order(Optional) Order of the Pade approximant. Default is 10.
[out]err(Optional) A state return flag. Without it the function is pure, and an error stops execution.
Returns
The matrix exponential \( e^{A} \), of the same kind and size as \( A \).
Note
The function form without err is pure; the form with err is not, because a pure function cannot return an error argument.
