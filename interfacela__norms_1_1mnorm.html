Detailed Description

Matrix norm: function interface.

nrm = mnorm(a, order [, dim]) returns the 1-, infinity- or Frobenius norm of the matrix a, from LAPACK's lange; for an array of rank 3 or higher, the norms of its matrices along the dimensions dim (default [1,2]). Without err the function is pure, and an error stops execution; mnorm(a, order [, dim], err) returns the error state instead.
